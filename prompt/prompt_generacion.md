# Prompt de generación de corpus LLM

Este archivo contiene el prompt utilizado para generar los corpus de ChatGPT y Copilot en el estudio.

## Prompt

```
[PENDIENTE: pegar aquí el texto completo del prompt]
```

## Parámetros de generación (ChatGPT)

El prompt se ejecutó con los parámetros por defecto de la interfaz web de ChatGPT (GPT-4) y Copilot al momento de la recolección (2023–2024). No se modificaron parámetros de temperatura, top-p ni penalizaciones.

## Instrucciones de uso

El prompt recibía como entrada el **título** de cada uno de los 52 artículos del corpus humano. Se iteró sobre todos los títulos de forma independiente, generando un texto completo por título en cada herramienta.
